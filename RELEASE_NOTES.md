# Release Notes

## v0.1.0 - Initial Release

**Release Date:** 2025-01-26

### Features
- Desktop application for managing npm registry configurations
- Visual interface to switch between npm registries
- Add custom registries with color-coding
- View current registry status
- Automatic detection of registry configuration
- Color-coded registry indicators for visual identification
- Toast notifications for status updates

### Technical Details
- Built with Tauri and React
- Windows support with NSIS installer
- Automatic release builds via GitHub Actions

### Installation
Download the Windows installer from the GitHub releases page and follow the installation prompts.

### What's Included
- Windows installer (.exe)
- Direct application executable
- File checksums for verification
